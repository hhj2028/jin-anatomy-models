# Licence

This repository contains 3D anatomy model data from several sources, each under its own Creative Commons licence. Attribution and the list of changes for every package are in `models/<package>/ATTRIBUTION.txt`.

| Material | Licence |
|---|---|
| Adapted model data from Z-Anatomy and Open3D Anatomy, original textures and connectors made for JIN Anatomy Studio | Creative Commons Attribution-ShareAlike 4.0 International — https://creativecommons.org/licenses/by-sa/4.0/legalcode |
| Unmodified or translated BodyParts3D, Human Reference Atlas and SPARC surfaces | Creative Commons Attribution 4.0 International — https://creativecommons.org/licenses/by/4.0/legalcode |

When you reuse this data, credit the original authors named in each ATTRIBUTION.txt, link the licence, state your changes, and license adaptations of CC BY-SA material under CC BY-SA 4.0.

Main sources:

- Z-Anatomy — Gauthier Kervyn, Marcin Zielinski, Lluis Vinent. https://github.com/Z-Anatomy/Models-of-human-anatomy (CC BY-SA 4.0)
- Open3D Anatomy / AnatomyTOOL — Open3D project, Eungyeol Lee, Daniël Jansma, Paul O.P. Gobée and contributors. https://anatomytool.org/open3dmodel-credit (model CC BY-SA 4.0)
- BodyParts3D — © The Database Center for Life Science. https://dbarchive.biosciencedbc.jp/en/bodyparts3d/ (CC BY 4.0)
- Human Reference Atlas — Kristen Browne & Heidi Schlehlein (2023), 3D Reference Organ Set for Female v1.5, HuBMAP. https://doi.org/10.48539/HBM352.BTSQ.586 (CC BY 4.0)
- SPARC — Lin, Christie, Chopovda & Nickerson (2026), Scaffold map — Human vagus nerve v7. https://doi.org/10.26275/tjzi-muqm (CC BY 4.0)
